## 1. 기술 지표 최적 파라미터

### 1.1 RSI (Relative Strength Index)

**기본 공식**
```
RSI = 100 - (100 / (1 + RS))
RS = 평균상승폭 / 평균하락폭  (n기간)
```

**파라미터별 용도 구분**

| 파라미터 | 용도 | 특징 |
|---------|------|------|
| RSI(2) | 초단기 평균회귀 | Larry Connors 전략, 과매도 10 이하 매수 |
| RSI(14) | 표준 (Welles Wilder 원안) | 과매수 70 / 과매도 30 기준 |
| RSI(21) | 중기 추세 추종 | 신호 감소, 신뢰도 향상 |

**실증 백테스트 결과**
- RSI(2) 전략 (S&P 500, 1993~): 평균 수익 0.5%/거래, 승률 75%, 단 큰 손실 구간 존재
- RSI(2) < 10 매수 + 5일 SMA 돌파 시 청산: 연 30.3% (1999~), 최대낙폭 35%
- RSI(2) < 5 진입 시 RSI < 10 진입보다 수익률 더 높음 (역치가 낮을수록 수익률 개선)
- MACD & RSI 조합: 승률 0.84~0.86 (단독 사용 대비 월등히 높음)

**한국 주식 적용 유의사항**
- RSI 모멘텀 전략(상승 → 추가 매수)은 한국 주식에서 모멘텀보다 **역투자전략이 더 유효**한 것으로 실증됨
- 강한 추세 구간에서는 RSI가 70~80에 머물며 오버바이 신호가 지속 → 단독 사용 금지
- 권장: RSI(14) + 추가 필터(ADX, 이동평균 방향) 조합

**실전 기준값**
```
과매수: RSI > 70 (강세장에서는 80으로 상향 조정)
과매도: RSI < 30 (약세장에서는 20으로 하향 조정)
중립: 40~60
다이버전스 신호: 가격 고점↑ + RSI 고점↓ (하락 다이버전스)
```

### 1.2 MACD (Moving Average Convergence Divergence)

**기본 공식**
```
MACD선 = EMA(12) - EMA(26)
시그널선 = EMA(MACD선, 9)
히스토그램 = MACD선 - 시그널선
```

**파라미터별 용도**

| 설정 | 용도 | 특징 |
|-----|------|------|
| (12, 26, 9) | 표준 (일봉 기준) | 대부분 시장에서 검증된 기본값 |
| (5, 13, 4) | 단기/스캘핑 | 신호 많지만 오신호 증가 |
| (8, 17, 6) | 데이트레이딩 | 속도와 신뢰도 균형 |
| (8, 24, 9) | 4시간봉 | 4H 차트에서 휩소 감소 |
| (19, 39, 9) | 장기 추세 | 안정적이나 신호 늦음 |

**백테스트 결과 (S&P 500 기준)**

| 전략 | CAGR | 평균 거래 수익 | 수익 팩터 | 최대낙폭 |
|-----|------|-------------|---------|---------|
| 기본 크로스오버 | 4.19% | 0.44% | 1.65 | 30% |
| 개선 (Slow < 0 조건) | 3.44% | 0.79% | 1.72 | 25% |
| 히스토그램 전략 | 4.79% | 0.95% | 4.22 | 16% |
| MACD + RSI 조합 | 6.36% | 0.76% | 2.45 | 16% |

**한국 주식 적용 유의사항**
- MACD는 **횡보 구간에서 골든크로스/데드크로스 빈발** → 오신호 많음
- ADX < 20 횡보장에서는 MACD 신호 무시 권장
- 히스토그램이 0선 위에서 양전환 후 증가 = 추세 가속 신호로 활용

### 1.3 볼린저밴드 (Bollinger Bands)

**기본 공식**
```
중심선 = SMA(20)
상단 = SMA(20) + 2 × 표준편차(20)
하단 = SMA(20) - 2 × 표준편차(20)

BBW (Bandwidth) = (상단 - 하단) / 중심선
%b = (종가 - 하단) / (상단 - 하단)
```

**표준 파라미터: (20, 2)**

| 파라미터 | 포함 확률 | 용도 |
|---------|---------|------|
| (20, 1.0) | ~68% | 단기 과열/침체 감지 |
| (20, 2.0) | ~95% | 표준 (John Bollinger 원안) |
| (20, 2.5) | ~99% | 강한 추세 구간 활용 |

**BBW 활용 (변동성 판단)**
```
스퀴즈 (횡보 후 폭발 대기): BBW 최근 6개월 최저 근방
확장 (추세 시작):            BBW 급격히 확대
정상 범위:                   종목별로 다르므로 상대 비교 필요
```

**%b 기반 매매 신호**
```
매수 구간: %b < 0.2 (하단 20% 이내) + MFI(10) < 20
매도 구간: %b > 0.8 (상단 20% 이내) + MFI(10) > 80
추세 강화: %b > 1.0 (상단 돌파) → 강한 상승 추세 확인
```

**한국 주식 적용 전략**
- 횡보 구간 (ADX < 20): 밴드 상단 → 매도, 하단 → 매수 (역추세 전략)
- 추세 구간 (ADX > 25): 밴드 중심선 회귀 후 방향으로 재진입 (추세 추종)
- **스퀴즈 이후 방향 돌파 시 강한 모멘텀 매매 가능**

### 1.4 스토캐스틱 (Stochastic Oscillator)

**기본 공식**
```
%K = (현재가 - n기간 최저) / (n기간 최고 - n기간 최저) × 100
%D = SMA(%K, m)  ← 시그널선
```

**파라미터 구분**

| 유형 | 파라미터 | 특징 |
|-----|---------|------|
| Fast Stochastic | %K(14), %D(3) | 민감, 오신호 많음 |
| Slow Stochastic | %K(14,3), %D(3) | 기본값, 균형 잡힘 |
| Full Stochastic | (14, 3, 3) | 파라미터 커스터마이즈 가능 |
| 초단기 | (5, 3, 3) | 변동성 큰 시장, 빠른 신호 |

**기준값**
```
과매수: %K > 80
과매도: %K < 20
골든크로스: %K가 %D를 상향 돌파 (과매도 구간에서 유효성 높음)
데드크로스: %K가 %D를 하향 돌파 (과매수 구간에서 유효성 높음)
```

**실전 활용 원칙**
- 단독 사용 금지 → RSI 또는 볼린저밴드와 조합
- 추세 구간에서는 지속적으로 과매수/과매도에 머물 수 있음
- 다이버전스 (가격 신고점 + Stochastic 하락) = 추세 반전 경고

## 2. 한국 주식 시장 특성

### 2.1 기본 구조

**거래 시간 (KST)**
```
정규장:          09:00 ~ 15:30
장전 시간외:     08:00 ~ 08:30  (전일 종가로 체결)
장후 시간외:     15:40 ~ 18:00  (당일 종가로 체결)
동시호가:        08:30 ~ 09:00  (매수/매도 호가 접수, 09:00에 일괄 체결)
장마감 동시호가: 15:20 ~ 15:30  (15:30에 일괄 체결)
```

**가격제한폭 (2015년 6월 15일부터 적용)**
```
상한가: +30%
하한가: -30%
예외: 상장 당일, 정리매매 종목
```

**시장 규모 (2026년 기준)**
```
KOSPI 상장 종목 수: 약 951개
KOSPI 시가총액:     최고 5,331조원 (2026년 2월 기준)
외국인 시가총액 비중: 약 26~27% (2023년, 최고점은 2004년 40.5%)
```

### 2.2 동시호가 (Call Auction) 매매 전략적 의미

**특성**
- 08:30~09:00: 매수/매도 호가가 쌓이지만 체결 안 됨
- 09:00에 단일가로 일괄 체결 → 갭업/갭다운 발생 원인
- 호가 집중 종목은 상한가(+30%) 또는 그 이상 갭으로 시가 결정 가능

**활용법**
- 08:30~09:00 동시호가 시세 = 당일 시가 방향 선행 지표
- 동시호가 매수 잔량 >> 매도 잔량 → 갭 상승 시가 예상
- **장 시작 직전 동시호가 잔량 불균형을 당일 방향 판단에 활용 가능**

### 2.3 프로그램 매매

**분류**
```
차익매매:  현물 + 선물 간 가격 차이를 이용한 무위험 차익거래
            - 매수 차익: 현물 < 선물 → 현물 매수 + 선물 매도
            - 매도 차익: 현물 > 선물 → 현물 매도 + 선물 매수
비차익매매: 단일 시장에서의 대규모 바스켓 매매 (전체의 약 98%)
            - ETF 연계 매매가 95% 이상
            - 외국인이 한국 주식 포트폴리오 비중 조정 시 사용
```

**규모 및 영향**
```
일일 프로그램 매매 규모: 통상 수백억~수천억원
대규모 시: 1조~2조원까지 출현 가능
옵션 만기일/쿼드러플 위칭데이: 청산 물량으로 지수 급등락 유발
```

**매매 전략적 활용**
- 프로그램 순매수 → 지수 단기 상승 압력
- 프로그램 순매도 + 외국인 동반 매도 → 강한 하락 신호
- 축적된 차익 잔고 규모(매수 차익 잔고 > 매도 차익 잔고)가 크면 만기일 충격 가능성 증가

### 2.4 외국인/기관 수급

**시장 참여자 역할**
```
외국인:  KOSPI 시가총액의 약 26~27% 보유 (2023년 기준)
         ETF 바스켓 중심 비차익 프로그램 매매
         환율 변동과 연동 (원화 약세 → 외국인 매도 압력)

기관:    투신, 보험, 연기금, 은행 등
         연기금은 장기 분산투자, 반대로 단기 충격 시 매수자 역할
         기관 수급은 반기/분기 말 포트폴리오 리밸런싱 영향

개인:    단기 변동성 유발, 역추세 매매 성향
```

**수급 분석 실전 기준**
```
강세 신호: 외국인 + 기관 동반 순매수
약세 신호: 외국인 + 기관 동반 순매도 + 개인 순매수 (개인 물량 받기)
중립:     외국인 매수 + 기관 매도 (또는 반대) → 방향성 불명확
```

## 3. 켈리 기준 (Kelly Criterion)

### 3.1 기본 공식

**이항 결과(Win/Loss) 버전**
```
f* = (b×p - q) / b

여기서:
  f* = 베팅 비율 (자본 대비)
  b  = 순이익률 (이길 때 순이익 / 베팅금)
  p  = 승률 (이길 확률)
  q  = 패율 = 1 - p
```

**손익비(R) 버전 (주식 실전 활용)**
```
f* = W - (1-W) / R

여기서:
  W = 승률 (Win Rate)
  R = 손익비 (평균 수익 / 평균 손실)
```

**계산 예시**
```
승률 55%, 손익비 1.5:1인 경우:
f* = 0.55 - (0.45 / 1.5) = 0.55 - 0.30 = 0.25 → 자본의 25% 투자

승률 60%, 손익비 2.0:1인 경우:
f* = 0.60 - (0.40 / 2.0) = 0.60 - 0.20 = 0.40 → 자본의 40% 투자

승률 45%, 손익비 2.0:1인 경우:
f* = 0.45 - (0.55 / 2.0) = 0.45 - 0.275 = 0.175 → 자본의 17.5% 투자
```

### 3.2 Fractional Kelly (분수 켈리)

**변형 버전별 특성**

| 버전 | 투자 비율 | 최적 성장률 대비 | 최대낙폭 |
|-----|---------|--------------|---------|
| Full Kelly (f*) | 100% | 100% | 매우 높음 |
| Half Kelly (f*/2) | 50% | ~75% | Full Kelly의 ~50% |
| Quarter Kelly (f*/4) | 25% | ~50% | 극도로 낮음 |

**실전 권장 사항**
```
대부분의 프로페셔널 트레이더: Half Kelly ~ Quarter Kelly 사용
이유:
  1. Full Kelly 계산에 필요한 승률/손익비가 정확하지 않을 수 있음
  2. 과베팅 시 기하급수적으로 파산 가능성 증가
  3. Half Kelly는 성장률의 75%를 얻으면서 낙폭은 절반으로 감소

주의: 켈리 f* × 2 초과 시 장기적으로 파산 확률 100%에 수렴
```

### 3.3 주식 실전 적용 시 수정 사항

**기본 켈리의 한계**
```
1. 거래비용 미반영 → 실제 f*보다 낮게 조정 필요
2. 상관관계 미고려 → 상관 높은 종목 동시 보유 시 포지션 분산 필요
3. 승률/손익비 추정 오류 → 보수적 추정 원칙 (낮은 승률, 낮은 손익비 가정)
4. 한국 주식 가격제한폭(±30%) → 극단적 갭 리스크 존재
```

**실전 수식 (조정 버전)**
```
실전 투자 비율 = f* × 안전계수 × 0.5 (Half Kelly)

안전계수 = 0.5~0.8  (불확실성, 거래비용, 유동성 반영)
최대 단일 종목 투자 = 전체 자본의 10~25% 권장
```

**포트폴리오 수준 적용**
```
다수 종목 보유 시:
- 각 종목별 Kelly 비율 계산 후 합산
- 합산 Kelly > 1인 경우 각 비율을 비례 축소
- 종목 간 상관관계 0.7 이상이면 같은 포지션으로 취급
```

## 4. 시장 국면 판단

### 4.1 ADX (Average Directional Index)

**기본 파라미터: ADX(14)**

**추세 강도 기준값**

| ADX 값 | 시장 상태 | 매매 전략 |
|--------|---------|---------|
| 0 ~ 20 | 추세 없음 (횡보) | 역추세 / 범위 매매 |
| 20 ~ 25 | 추세 형성 초기 (회색지대) | 추세 확인 후 진입 |
| 25 ~ 40 | 강한 추세 | 추세 추종 전략 |
| 40 ~ 60 | 매우 강한 추세 | 추세 추종 (과열 주의) |
| 60 이상 | 극단적 추세 | 조기 이익 실현 고려 |

**+DI / -DI 활용**
```
매수 신호: +DI가 -DI를 상향 돌파 AND ADX > 25 AND ADX 상승 중
매도 신호: -DI가 +DI를 상향 돌파 AND ADX > 25 AND ADX 상승 중
ADX < 20 구간의 크로스오버: 신뢰도 낮음 → 무시 권장
ADX 방향이 하락 중이면 추세 약화 신호
```

**핵심 원칙**
- ADX가 25에서 40으로 상승 중 = 추세 강화 → 추세 추종 유리
- ADX가 40에서 25로 하락 중 = 추세 약화 (가격은 계속 움직여도)
- ADX만으로는 방향 알 수 없음 → +DI/-DI로 방향 확인

### 4.2 VIX / VKOSPI (변동성 지수)

**VIX (S&P 500 기준)**

| VIX | 시장 상태 |
|-----|---------|
| < 15 | 매우 안정, 과도한 낙관 경계 |
| 15 ~ 20 | 안정적 정상 |
| 20 ~ 30 | 불안감 증가, 정상 변동성 상한 |
| 30 ~ 40 | 높은 변동성, 시장 공포 |
| 40 이상 | 극도의 공포 |
| 60 이상 | 시장 위기 (2008년 금융위기, 2020년 코로나) |

**VKOSPI (한국 KOSPI200 기준)**

| VKOSPI | 시장 상태 | 전략 시사점 |
|--------|---------|-----------|
| 15 미만 | 안정, 낙관 | 매수 포지션 유지 |
| 15 ~ 20 | 정상 범위 | 중립 |
| 20 ~ 30 | 경계 구간 | 포지션 축소 검토 |
| 30 이상 | 공포 구간 | 역발상 매수 기회 탐색 |
| 40 이상 | 극단적 공포 | 강력한 역발상 매수 시점 |
| 71 (2020년 3월) | 역사적 최고치 | 바닥권 신호 (이후 급반등) |

**VKOSPI 역발상 원칙**
```
VKOSPI 급등 = 시장 공포 최고조 = 단기 바닥 근방일 가능성 높음
VKOSPI 최저 = 과도한 낙관 = 조정 가능성 증가

활용법:
- VKOSPI > 30 진입 시: 분할 매수 전략 시작
- VKOSPI > 40 진입 시: 적극적 역발상 매수
- VKOSPI < 15 지속 시: 과열 경계, 손절선 타이트하게 설정
```

### 4.3 볼린저밴드 폭 (BBW)

**계산 공식**
```
BBW = (상단 밴드 - 하단 밴드) / 중심선(SMA)
```

**국면 판단**
```
스퀴즈 (BBW 수축):
  - BBW가 최근 N기간(보통 125일 = 약 6개월) 최저 수준
  - 의미: 변동성 최저 → 큰 방향 돌파 임박 (방향은 알 수 없음)
  - 전략: 돌파 방향으로 진입, 손절 타이트하게

확장 (BBW 급증):
  - 추세 시작 및 강화 신호
  - BBW 급증 초기: 추세 추종 진입 기회

정상 상태:
  - 종목별 상대 비교 필요 (절대값 기준 없음)
```

### 4.4 종합 국면 판단 매트릭스

```
추세 구간:
  조건: ADX > 25 (상승) + BBW 확장 + VKOSPI < 25
  전략: 이동평균 추종, 모멘텀 전략, 손절 트레일링

횡보 구간:
  조건: ADX < 20 + BBW 좁음 (스퀴즈)
  전략: 볼린저밴드 역추세, RSI 과매수/과매도 매매

고변동성 공포 구간:
  조건: VKOSPI > 30 + VIX > 30 + BBW 급팽창
  전략: 포지션 축소, 분할 역발상 매수, 변동성 매매

과열 구간:
  조건: ADX 높지만 하락 + VKOSPI < 15 + RSI > 70
  전략: 이익 실현, 신규 진입 보류
```

## 5. 팩터 투자 (Factor Investing)

### 5.1 주요 팩터 개요

**팩터 정의**
- 팩터 강도가 높은 종목으로 구성된 포트폴리오는 미래 수익이 높을 것으로 기대
- 한국 시장에서 실증적으로 유효성이 검증된 팩터들

### 5.2 모멘텀 팩터

**정의 및 구분**
```
가격 모멘텀:
  단기 모멘텀: 1주~1개월 수익률
  중기 모멘텀: 3~12개월 수익률 (가장 유효한 구간)
  장기 모멘텀: 3~5년 수익률 (반전 효과로 역방향)

이익 모멘텀:
  기업 이익 추정치 상향 조정 추세
  EPS 서프라이즈 지속성
```

**한국 주식 실증 결과**
```
유효 구간: 3~12개월 수익률 모멘텀 (중기)
연구 기간: 1981~2012년 (한국 주식, 5,475개 비금융 표본)
핵심 발견:
  - 한국 시장에서는 모멘텀 전략보다 역투자전략(Contrarian)이 더 유효
  - 12개월 이상 장기 과거성과를 사용하면 모멘텀 효과 감소/소멸
  - 3~12개월 구간: 모멘텀 효과 뚜렷
  - 하루~1주 단기, 수년 장기: 모멘텀 효과 약함
```

**실전 적용 기준**
```
모멘텀 종목 선정 (중기):
  - 최근 12개월 수익률 상위 30개 종목 선발
  - 단, 최근 1개월 수익률 제외 (단기 반전 효과 차단)
  즉, 12개월 수익률 기준으로 하되 최근 1개월은 차감

듀얼 모멘텀:
  - 절대 모멘텀: 시장 자체가 양(+) 수익률일 때만 투자
  - 상대 모멘텀: 시장 내 상대 순위 상위 종목 선택
```

### 5.3 저변동성 팩터 (Low Volatility)

**정의**
- 저변동성 이상현상: 이론과 반대로 변동성 낮은 주식이 높은 수익률을 보임

**한국 시장 실증 결과 (핵심)**
```
연구 기간: 1990년 1월 ~ 2012년 12월 (KOSPI 상장 주식)
측정 지표: 고유변동성(Idiosyncratic Volatility)

결과:
  저변동성 포트폴리오(P1) 보유수익: +218% (거래비용 차감 후)
  고변동성 포트폴리오(P5) 보유수익: -98% (거래비용 차감 후)

  헤지 전략 (P1 매수 + P5 매도):
    월평균 초과수익률: 1.57% (통계적으로 유의)
    2000년 이후만 계산 시에도 유의
    저가주/비유동성 주식 제거 후: 월평균 1.82%
    포트폴리오 재구성 주기 늘려도 수익 지속
```

**원인 분석**
```
고변동성 주식의 과대평가 경향:
  - 거래회전율 높고 수익률 왜도(Skewness)가 높은 복권형 주식
  - 개인투자자(노이즈 투자자)의 투기적 수요
  - 과대평가가 사후 조정되면서 저수익 발생
```

**실전 포트폴리오 구성**
```
저변동성 선정 기준:
  일별 수익률 표준편차 (최근 60~252일)
  연환산 변동성 = 일별 표준편차 × √252

종목 선정:
  KOSPI 전체에서 변동성 하위 20~30% 종목 선발
  유동성 필터 적용 (일평균 거래대금 일정 기준 이상)

리밸런싱: 월별 또는 분기별
```

### 5.4 퀄리티 팩터

**측정 지표 (F-Score, Piotroski)**
```
수익성 지표 (3가지):
  1. ROA > 0
  2. 영업현금흐름 > 0
  3. ROA 전년 대비 개선

레버리지/유동성 (3가지):
  4. 장기부채비율 감소
  5. 유동비율 증가
  6. 주식 추가 발행 없음

운영 효율성 (3가지):
  7. 총자산이익률(매출총이익/총자산) 개선
  8. 자산회전율 개선
  9. 발생주의 = (영업현금흐름 - ROA) < 0

F-Score 해석:
  8~9점: 강한 매수 신호
  0~2점: 강한 매도/공매도 신호
  3~7점: 중립 (일반적으로 대부분 이 구간)
```

**QMJ (Quality Minus Junk) 구성**
```
퀄리티 지표 = 수익성 + 성장성 + 안전성의 종합 점수
  - 수익성: ROE, ROA, 매출이익률
  - 성장성: 이익 성장률, 매출 성장률
  - 안전성: 부채비율, 이자보상배율

고퀄리티 포트폴리오 - 저퀄리티 포트폴리오 = QMJ 알파 추출
```

### 5.5 밸류 팩터

**주요 지표**
```
PBR (Price-to-Book Ratio):  낮을수록 저평가
PER (Price-to-Earnings):    낮을수록 저평가
PCR (Price-to-Cash Flow):   현금흐름 기반 밸류
PSR (Price-to-Sales):       매출 기반 밸류 (성장주에 유용)

복합 밸류 지표 = PBR + PER + PCR + PSR 순위 평균
  → 단일 지표보다 복합 지표가 더 안정적
```

**한국 시장 특이점**
```
PBR이 낮은 종목 = 지주회사, 금융주, 전통 제조업 비중 높음
홀딩스 회사 할인: 지주회사는 구조적으로 PBR이 낮음 → 함정 주의
금융주: 업종 특성상 레버리지 구조 다름 → 별도 취급 필요
```

### 5.6 팩터 조합 전략

**멀티팩터 포트폴리오**
```
퀄리티 + 저변동성:
  - 재무 건전한 기업 중 변동성 낮은 종목
  - 안정적 초과수익, 낙폭 방어력 강함

모멘텀 + 밸류 (VAL-MOM):
  - 저평가 되었으나 상승 모멘텀 시작된 종목
  - 단독보다 조합이 샤프 비율 개선

팩터 로테이션:
  - 경기 확장기: 모멘텀, 성장 팩터
  - 경기 수축기: 저변동성, 퀄리티, 배당 팩터
  - 시장 반등기: 밸류 팩터
```

**팩터별 유효 기간**

| 팩터 | 리밸런싱 권장 주기 | 유효성 지속 기간 |
|-----|---------------|--------------|
| 모멘텀 | 월별~분기별 | 3~12개월 |
| 저변동성 | 월별~분기별 | 장기 지속 |
| 퀄리티 | 분기별~반기별 | 장기 지속 |
| 밸류 | 반기별~연간 | 3~5년 |

## 6. 종합 활용 가이드 (AI 어시스턴트용 의사결정 흐름)

### 6.1 매매 전 체크리스트

```
Step 1: 시장 국면 판단
  [ ] VKOSPI 수준 확인 (15/20/30 기준)
  [ ] ADX(14) 확인 (20/25 기준)
  [ ] BBW 스퀴즈 여부 확인

Step 2: 국면별 전략 선택
  추세 (ADX>25): RSI 모멘텀, MACD 추세, 볼린저밴드 중심선 이탈
  횡보 (ADX<20): RSI 역추세, 볼린저밴드 상/하단, Stochastic 크로스
  공포 (VKOSPI>30): 역발상 매수 준비, 켈리 비율 보수적 설정

Step 3: 수급 확인
  [ ] 외국인 순매수/매도 방향
  [ ] 기관 순매수/매도 방향
  [ ] 프로그램 매매 규모 및 방향

Step 4: 포지션 사이징 (켈리 기준)
  [ ] 전략 승률(W) 추정
  [ ] 평균 손익비(R) 계산
  [ ] Half Kelly 계산: (W - (1-W)/R) × 0.5
  [ ] 최대 25% 상한 적용
```

### 6.2 지표 조합 권장 매트릭스

| 시장 국면 | 주 지표 | 보조 지표 | 필터 |
|---------|--------|---------|-----|
| 강한 상승 추세 | MACD 히스토그램 | RSI(14) | ADX > 25 |
| 약한 상승 추세 | 볼린저밴드 %b | Stochastic | ADX 15~25 |
| 횡보 | RSI(14) 역추세 | 볼린저밴드 | ADX < 20 |
| 고변동성 | VKOSPI 역발상 | RSI(2) | VKOSPI > 30 |
| 하락 추세 | MACD 데드크로스 | RSI 다이버전스 | ADX > 25 |
