# 키움 브릿지 설계

**날짜**: 2026-02-24
**상태**: ✅ 확정

---

## 역할

- FastAPI 백엔드와 키움 OCX 사이의 중간 다리
- 별도 프로세스로 실행 (PyQt5 이벤트 루프 분리)
- Redis를 통해 백엔드와 통신

---

## 통신 구조

```
[FastAPI 백엔드]
      ↓ 명령 발행
   Redis
      ↓ 명령 수신
[Kiwoom Bridge]
      ↓ OCX 호출
   키움 서버
      ↓ 결과 이벤트
[Kiwoom Bridge]
      ↓ 결과 발행
   Redis
      ↓ 결과 수신
[FastAPI 백엔드]
```

---

## Redis 채널

| 채널 | 방향 | 설명 |
|------|------|------|
| `autostock:commands` | 백엔드 → 브릿지 | 명령 전달 |
| `autostock:events` | 브릿지 → 백엔드 | 결과/이벤트 전달 |

---

## 메시지 구조

### 백엔드 → 브릿지 (명령)

#### 로그인
```json
{
  "type": "CONNECT"
}
```

#### 매수 주문
```json
{
  "type": "BUY",
  "bot_id": 1,
  "ticker": "005930",
  "quantity": 10,
  "price": 0
}
```
> price가 0이면 시장가

#### 매도 주문
```json
{
  "type": "SELL",
  "bot_id": 1,
  "ticker": "005930",
  "quantity": 10,
  "price": 0
}
```

#### 잔고 조회
```json
{
  "type": "GET_BALANCE",
  "bot_id": 1
}
```

#### 포지션 조회
```json
{
  "type": "GET_POSITIONS",
  "bot_id": 1
}
```

---

### 브릿지 → 백엔드 (결과/이벤트)

#### 로그인 결과
```json
{
  "type": "CONNECTED",
  "success": true
}
```

#### 주문 체결 결과
```json
{
  "type": "ORDER_RESULT",
  "success": true,
  "ticker": "005930",
  "quantity": 10,
  "filled_price": 75000,
  "order_number": "123456"
}
```

#### 실시간 현재가
```json
{
  "type": "PRICE_UPDATE",
  "ticker": "005930",
  "price": 75000
}
```

## Mock 모드

- 브릿지 자리에 Mock 프로세스가 대체
- 동일한 메시지 구조 사용
- 백엔드는 상대가 키움인지 Mock인지 모름
- 설정값 하나로 전환 가능

```
BROKER_MODE=mock   → Mock 브릿지 실행
BROKER_MODE=real   → 키움 브릿지 실행
```
