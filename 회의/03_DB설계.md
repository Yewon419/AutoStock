## Strategy 도메인

### strategies
```
id
user_id          → FK users
name
description
conditions       → JSON
                   {
                     "conditions": [
                       {
                         "indicator": "RSI",
                         "condition": "below",
                         "value": 30
                       }
                     ]
                   }
is_active
created_at
updated_at
```

#### 지원 지표 (32개, 기존 happystocklife 동일)
| 카테고리 | 지표 |
|----------|------|
| 추세 | SMA, EMA, WMA, TEMA, HMA, MACD |
| 모멘텀 | RSI, STOCH, STOCHRSI, WILLR, CCI, ADX, AROON 등 |
| 변동성 | Bollinger Bands, ATR, Keltner, Donchian |
| 거래량 | OBV, AD, CMF, MFI, VWAP, PVT |
| 지지저항 | PIVOT, FIB, ICHIMOKU, ZIGZAG, TRIX |

#### 지원 조건 유형
- `above` / `below` → 임계값 이상/이하
- `between` → 범위
- `golden_cross` / `dead_cross` → 크로스

## Trading 도메인

### accounts
```
id
user_id          → FK users

```

### trading_bots
```
id
user_id          → FK users
name
status           → RUNNING / STOPPED / ERROR
strategy_id      → FK strategies
account_id       → FK accounts

[리스크 설정]
stop_loss_pct        → 종목 손절 (%)
take_profit_pct      → 종목 익절 (%)
max_drawdown_pct     → 전체 계좌 최대 낙폭 (%) → 초과 시 ERROR
position_size_pct    → 종목당 투자 비율 (%)
max_positions        → 최대 보유 종목 수
max_daily_trades     → 일일 최대 거래 횟수

[거래 시간]
trading_start_time   → 거래 시작 시간 (기본 09:00)
trading_end_time     → 거래 종료 시간 (기본 15:20)

created_at
updated_at
```

## 핵심 설계 원칙

1. **TradingBot 중심** - 모든 거래 데이터는 봇 단위로 관리
2. **orders / executions 분리** - 주문(의도)과 체결(결과) 분리, 키움 브릿지 비동기 처리 대응
3. **positions** - 현재 상태 스냅샷, 체결마다 업데이트
4. **bot_reports** - 매일 장 마감 후 미리 계산해서 저장, 빠른 조회
5. **TimescaleDB** - stock_prices, technical_indicators 시계열 최적화
6. **암호화** - 계좌번호 Fernet 암호화 저장
