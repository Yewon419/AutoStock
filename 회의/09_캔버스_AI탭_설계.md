# 09. AI 캔버스 탭 설계

**날짜**: 2026-03-13
**상태**: 구현 중

---

## 개요

AI 분석 기능을 DB 설계 도구 스타일의 **비주얼 노드 캔버스**로 재구성.
사용자가 노드를 자유롭게 생성·삭제·이동하고, 연결선으로 파이프라인을 조립한다.
연결된 노드끼리만 실행되며, AI 어시스턴트가 항상 붙어 자동 구성을 돕는다.

---

## 노드 카탈로그

### 소스 노드 (파랑 `#0e7490`) — 데이터 공급
| 노드 타입 | 레이블 | 출력 포트 | 실행 방식 |
|---|---|---|---|
| `marketContext` | 시장 컨텍스트 | `market_data` | GET /ai/market-context (동기) |
| `techIndicators` | 기술 지표 DB | `indicator_data` | GET /ai/tech-indicators-summary (동기) |
| `mlScores` | ML 스코어 캐시 | `ml_scores` | GET /ai/scores (동기) |

### 처리 노드 (보라 `#7c3aed`) — 연산
| 노드 타입 | 레이블 | 입력 포트 | 출력 포트 | 실행 방식 |
|---|---|---|---|---|
| `mlModel` | ML 모델 | `indicator_data`(선택) | `ml_scores` | POST /ai/score (Celery 비동기) |
| `llmGenerator` | LLM 전략 생성 | `market_data`(선택), `ml_scores`(선택) | `strategy` | POST /ai/generate-strategy (Celery) |
| `backtest` | 백테스트 | `strategy`(필수) | `backtest_result` | POST /ai/backtest-strategy (Celery) |

### 출력 노드 (초록 `#059669`) — 결과 적용
| 노드 타입 | 레이블 | 입력 포트 | 실행 방식 |
|---|---|---|---|
| `botApply` | 봇 적용 | `strategy`(필수) | PUT /bots/{id} (동기) |

## 연결 규칙 (유효한 엣지)

```
marketContext.market_data    → llmGenerator.market_data
techIndicators.indicator_data → mlModel.indicator_data
mlScores.ml_scores           → llmGenerator.ml_scores
mlModel.ml_scores            → llmGenerator.ml_scores
llmGenerator.strategy        → backtest.strategy
llmGenerator.strategy        → botApply.strategy
```

---

## 실행 흐름

1. 사용자가 노드의 **▶ 실행** 클릭
2. 필수 입력 포트에 연결된 상위 노드 결과 수집
3. API 호출 → 노드 상태: `idle → running → success/error`
4. 결과를 `data.result`에 저장
5. 출력 엣지 **animated: true** (흐름 애니메이션 활성화)
6. 다운스트림 노드는 이 결과를 자동으로 활용 가능

### 노드 상태
- `idle`: 기본 (회색 점)
- `running`: 실행 중 (파란 맥박)
- `success`: 완료 (녹색 점)
- `error`: 오류 (빨간 점)

## AI 어시스턴트 명령 체계

### 요청 (Frontend → Backend)
```json
{
  "message": "추천 파이프라인 구성해줘",
  "canvas": {
    "nodes": [{"id": "n1", "type": "marketContext", "status": "success"}],
    "edges": []
  }
}
```

### 응답 (Backend → Frontend)
```json
{
  "reply": "ML 연동 풀 파이프라인을 구성했습니다.",
  "commands": [
    { "type": "clear" },
    { "type": "add_node", "node_type": "marketContext", "x": 80, "y": 120 },
    { "type": "add_node", "node_type": "mlModel",       "x": 340, "y": 220 },
    { "type": "add_node", "node_type": "llmGenerator",  "x": 600, "y": 120 },
    { "type": "connect", "source_type": "marketContext", "target_type": "llmGenerator",
      "source_handle": "market_data", "target_handle": "market_data" },
    { "type": "run_node", "node_type": "mlModel" }
  ]
}
```

### command 타입
| type | 필드 | 동작 |
|---|---|---|
| `clear` | - | 캔버스 전체 초기화 |
| `add_node` | node_type, x, y | 노드 추가 |
| `connect` | source_type, target_type, source_handle, target_handle | 엣지 생성 |
| `remove_node` | node_type | 해당 타입 노드 삭제 |
| `run_node` | node_type | 해당 노드 실행 트리거 |
