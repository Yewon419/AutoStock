# AutoStock 주식 전문 지식 베이스

## 1. 한국 주식 시장 기본 사항

### 거래 규칙
- 거래시간: 09:00~15:30 (정규장), 동시호가 08:30~09:00, 15:20~15:30
- 가격제한폭: ±30% (2015년 6월 이후)
- 결제: T+2일 (매수 후 2영업일 결제)
- 서킷브레이커: 전일 대비 -8% 시 20분 거래 중단
- 사이드카: 선물 1분간 ±5% 시 5분 프로그램매매 중단
- 공매도: KOSPI200·KOSDAQ150 종목만 허용 (개인 제한)
- 수수료+세금: 약 0.3% (매도 시 증권거래세 0.18% 포함)

### KOSPI vs KOSDAQ 특성
| 항목 | KOSPI | KOSDAQ |
|------|-------|--------|
| 종목 수 | 약 800개 | 약 1,600개 |
| 시가총액 규모 | 대형주 중심 | 중소형·성장주 중심 |
| 변동성 | 낮음 | 높음 (ATR 승수 더 크게 설정 필요) |
| 외인 영향 | 크다 (시총 26~27%) | 상대적으로 작다 |
| 특성 | 경기 민감, 수출주 | 바이오·IT·2차전지 |

### 수급 해석
- 외국인: 장기 방향성 지표. 3일 이상 연속 순매수 = 강세 신호
- 기관: 단기 수급. 프로그램 매수 동반 시 추세 강화
- 개인: 역발상 지표로 활용 가능 (개인 과매수 → 고점 경계)
- 공매도 잔고 급증: 해당 종목 하락 압력 증가


## 2. 기술 지표 해석 기준

### RSI (Relative Strength Index) — 기간: 14일 표준
| 구간 | 해석 | 대응 |
|------|------|------|
| < 20 | 극단적 과매도 | 강한 매수 탐색 (30점) |
| 20~30 | 과매도 | 매수 탐색 (15~25점) |
| 30~50 | 약세 구간 | 관망 |
| 50~70 | 강세 구간 | 보유 또는 추가 매수 |
| 70~80 | 과매수 | 익절 25% 고려 |
| > 80 | 극단적 과매수 | 익절 50% 이상 |

- RSI(2): Larry Connors 단기 전략용 — 10 이하 매수 + 5일SMA 상향돌파 청산. 승률 75%, 연 30% (낙폭 35%) [출처: QuantifiedStrategies]
- **한국 특이점**: 단기 과매도 역투자가 모멘텀보다 실증적으로 더 유효 [한국증권학회 1981~2012 실증]
- RSI 다이버전스: 가격 신고가 but RSI 전고점 미갱신 → 하락 반전 경고

### MACD (12, 26, 9) — 표준 파라미터
- 골든크로스 (MACD > Signal): 매수 신호 (20점)
- 데드크로스 (MACD < Signal): 매도 신호, 50% 부분 매도
- 히스토그램 양수+감소: 추세 약화, 25% 부분 매도 준비
- 히스토그램 0선 상향 돌파: 강한 매수 신호
- **MACD + RSI 조합**: 단독 대비 승률 84~86%, CAGR 6.36% [arxiv.org 실증]
- **주의**: ADX < 20 횡보 구간에서 오신호 빈발 → ADX 필터 필수

### 볼린저 밴드 (20일, 표준편차 2)
- BB하단 터치 (가격 ≤ BB하단×1.02): 반발 매수 탐색
- BB상단 돌파: 강한 추세 지속 OR 과매수 익절 신호
- BB폭(BBW) 6개월 최저 근방 → 스퀴즈 → 큰 방향 돌파 임박
- %b < 0.2 + MFI < 20: 강한 매수 조합
- %b > 0.8 + MFI > 80: 강한 매도 조합
- 볼린저 패턴 (현대로템형): MA하향돌파 → BB하단 반발 → MA상향돌파 + BB상단 돌파 = V자 회복

### 이동평균선 (MA)
| 기간 | 용도 |
|------|------|
| MA5, MA10 | 초단기 (단타용) |
| MA20 | 단기 추세 (핵심 기준선) |
| MA50, MA60 | 중기 추세 |
| MA120 | 장기 추세 (6개월선) |
| MA200 | 장기 추세 (연간선, 상승장 기준선) |

- 골든크로스 (MA20 > MA50): 추세 상승 전환 (25점)
- 데드크로스 (MA20 < MA50): 추세 하락 전환, 매도 신호
- 정배열 (MA5 > MA20 > MA60 > MA120): 강세장
- 역배열: 약세장, 매수 자제

### ADX (평균방향지수) — 기간: 14일
| ADX 값 | 시장 상태 | 전략 |
|---------|----------|------|
| < 20 | 횡보/방향성 없음 | 역투자(RSI 반전) 전략 유리, MACD 오신호 많음 |
| 20~25 | 추세 형성 중 | 추세추종 주의 진입 |
| 25~40 | 강한 추세 | 추세추종 전략 유리, 손절 느슨하게 |
| > 40 | 매우 강한 추세 | 추세 지속, 역투자 위험 |

### 스토캐스틱 (14, 3, 3) Slow
- K < 20, D < 20: 과매도 매수 탐색
- K > 80, D > 80: 과매수 매도 탐색
- K가 D 상향돌파 (20 이하에서): 매수 신호
- K가 D 하향돌파 (80 이상에서): 매도 신호

### ATR (Average True Range) — 기간: 14일
- 변동성 측정 도구 (방향성 없음)
- 손절가 = 진입가 - (ATR × 승수)
- ATR 승수 시장별 기준:

| 시장 상태 | ADX/ATR 기준 | ATR 승수 |
|----------|-------------|---------|
| 횡보 (RANGING) | ADX < 20 | 0.8× (타이트) |
| 추세 (TRENDING) | ADX ≥ 25 | 1.0× (기본) |
| 변동성 확장 | ATR 상위 20% | 3.0+ (느슨) |
| KOSDAQ | - | KOSPI 대비 1.2~1.5배 |

### VKOSPI (한국판 공포지수)
| VKOSPI | 해석 | 전략 |
|--------|------|------|
| 15 이하 | 과도한 낙관, 주의 | |
| 15~20 | 안정 구간 | 정상 운영 |
| 20~30 | 불안 | 포지션 축소 |
| 30~40 | 공포 | 역발상 매수 탐색 시작 |
| 40+ | 극단적 공포 | 역발상 적극 매수 (분할) |
| 71 | 2020년 코로나 최고치 → 이후 급반등 | |

### OBV (On-Balance Volume)
- OBV 신고가 + 가격 신고가 미갱신: 약세 다이버전스 → 하락 경고
- OBV 상승 + 가격 횡보: 세력 매집 신호

### VWAP (거래량가중평균가)
- 당일 VWAP 위에서 거래 = 매수세 우위
- 단타 핵심 지표: VWAP 대비 ±% 기준
- 기관·외인이 VWAP 기준으로 매매


## 3. 매매 전략 유형

### 스윙 트레이딩 (3일~수주)
**매수 조건 조합 (점수제 권장)**:
1. RSI < 30 (15~30점)
2. MA20 > MA50 상승 추세 (25점)
3. MACD 골든크로스 (20점)
4. 거래량 평균 대비 1.5배+ (10~15점)
5. Close > MA200 장기 상승 추세 (10점)
→ **총점 50점 이상 시 매수**

**매도 조건**:
- 1차 익절: RSI > 70 (25% 매도)
- 2차 익절: RSI > 80 (추가 50% 매도)
- 손절: 진입가 -5~7% (ATR 기반 동적 손절 권장)
- 추세 반전: MA20 < MA50 데드크로스 (50% 매도)

### 단타 (당일~2일)
**매수 조건**:
- RSI < 35 + 거래량 2배+ (핵심 조합)
- VWAP 대비 가격 위치 양수
- MACD 히스토그램 골든크로스 + 거래량 1.5배

**매도 조건**:
- 당일 목표: 진입가 +3~5%
- 손절: 진입가 -2%
- 트레일링 스탑: 고점 대비 -1.5%

### 볼린저 밴드 돌파 패턴
1. MA20 아래로 하향돌파 (약세)
2. BB하단 터치 후 반발
3. MA20, MA60 상향 돌파
4. BB상단 돌파 + 거래량 급증
→ **핵심 패턴: 총점 50점 이상** (하단반발 25pts + MA상향 30pts + 거래량 10pts + RSI 10pts)

### 추세추종 전략
- ADX ≥ 25 확인 후 진입
- 정배열(MA5 > MA20 > MA60) 확인
- 눌림목 매수: RSI 40~60 + ADX > 25 (강세장 눌림목)
- 손절: ATR × 1.0~1.1


## 4. 리스크 관리 원칙

### 포지션 사이징 — 켈리 공식
```
f* = W - (1-W)/R
  W = 승률, R = 손익비 (평균수익/평균손실)

예) 승률 55%, 손익비 1.5 → f* = 0.55 - 0.45/1.5 = 0.25 (25%)
```
- **Half-Kelly 권장**: f*/2 → 낙폭 절반, 성장률 75% 유지
- 실전 적용: f* × 0.5 × 안전계수(0.5~0.8)
- 단일 종목 최대: 포트폴리오의 25% 이내
- f* × 2 초과 시 장기 파산 확률 100% [Kelly Criterion 수학적 증명]

### 기본 리스크 파라미터 (HappyStockLife 실증값)
| 항목 | 기본값 | 설명 |
|------|--------|------|
| 포지션당 비율 | 총자산의 5% | 단일 매수 비중 |
| 최대 동시 보유 | 10종목 | 분산 |
| 손절 | -5% | 기본 하드 손절 |
| 목표가 | +10% | 기본 익절 |
| 최대 MDD | 15% | 초과 시 매수 중단 |
| 일일 거래 한도 | 20회 | 과매매 방지 |

### 3계층 매도 신호 (우선순위)
**CRITICAL (즉시 전량 매도)**:
- ATR 기반 손절가 이탈
- 고정 손실 -5% 이탈
- Time Stop: 5일 이상 보유 + 수익률 ≤ 0

**HIGH (50% 부분 매도)**:
- MACD 데드크로스 (MACD < Signal, MACD > 0)
- MA20 < MA50 데드크로스
- 거래량 급증(2배+) + 수익률 > 5% (거래량 절정)
- RSI 70 하향돌파

**MEDIUM (25~33% 부분 매도)**:
- 피보나치 127.2% 도달: 30% 매도
- 피보나치 161.8% 도달: 50% 매도
- 피보나치 261.8% 도달: 전량 매도
- BB상단 터치: 25% 익절
- RSI 70~80: 25% 익절

### MDD(최대낙폭) 관리
```
MDD = (현재자산 - 최고점자산) / 최고점자산 × 100
MDD ≤ -15%: 신규 매수 전면 중단
MDD ≤ -20%: 기존 포지션 50% 강제 청산 고려
```

### 손익비 (Risk-Reward Ratio)
- 최소 R/R = 1:1.5 이상 유지
- 1R (6.5% 수익): 33% 청산 + 손절을 본절(진입가)로 이동
- 2R (13% 수익): 50% 청산
- 3R (20% 수익): 전량 청산 또는 트레일링 스탑 타이트


## 5. 시장 국면 판단 (Market Regime)

### 국면 분류 기준
| 국면 | 조건 | 최적 전략 |
|------|------|----------|
| 강한 추세 | ADX ≥ 25 + ATR 상위 20% | 추세추종, 느슨한 손절 |
| 일반 추세 | ADX 20~25 | 추세추종 + 모멘텀 |
| 횡보 | ADX < 20 | 역투자(RSI 반전), MACD 필터 |
| 공포 장세 | VKOSPI 30+ | 역발상 분할매수 탐색 |
| 과열 장세 | VKOSPI 15- | 포지션 축소, 신규 매수 자제 |

### 국면별 파라미터 조정
- **횡보 장세**: ATR 승수 0.8× (타이트), RSI 반전 전략 우선
- **추세 장세**: ATR 승수 1.1×, 손절 더 느슨, 추세추종
- **변동성 확장**: ATR 승수 3.0+, 포지션 크기 50% 축소


## 6. 팩터 투자 (한국 실증 결과)

### 저변동성 팩터 [한국증권학회 1990~2012 실증]
- 저변동성 포트: +218% vs 고변동성 포트: -98%
- P1(저변동성) 매수 + P5(고변동성) 매도: **월평균 1.57% 초과수익** (통계적 유의)
- **핵심 인사이트**: 변동성 낮은 우량주가 장기적으로 고변동성 종목보다 수익 월등

### 모멘텀 팩터 [1981~2012 한국 실증]
- 유효 구간: **3~12개월 중기 모멘텀**
- 단기(1주 이하)·장기(3년+): 효과 미미
- **한국 특이점**: 순수 모멘텀보다 역투자전략이 더 유효

### 퀄리티 팩터 (Piotroski F-Score)
- F-Score 8~9: 강한 매수 신호 (재무 건전성 우수)
- F-Score 0~2: 매도/공매도 신호 (재무 악화)

### 밸류 팩터
- 단일 지표(PER, PBR 등) 보다 **복합 지표** (PBR+PER+PCR+PSR) 사용 권장
- 한국은 PBR < 1.0 종목 많음 → 저PBR 스크리닝 유효
